## 缺格分类与守恒

采样观察器只累计原因，不参与盘口选择。网格回调范围右端排他，交易日历
区间 `(open,close]`，暂停、休市不计入交易网格。以可信接收时间结算网格，
不会由不可信时间推进网格；刚在边界到达的消息仍只能用于下一个网格。
长空档以范围计数，不展开为虚构行情。

| 状态 | 含义 |
| --- | --- |
| emitted | 已生成且来源属于同一开放时段的有效快照 |
| emitted_preopen_source | 已生成但报价来自休市前，下游日历拒绝 |
| stale_completed_book | 可信完成盘口超过声明的最大年龄 |
| incomplete_event | 正在接收事件，尚无可用的事件末尾盘口 |
| bad_book_flag | 完成消息带可能损坏盘口标记 |
| invalid_completed_book | 完成盘口不满足现有双边价格/数量校验 |
| unreliable_receive_state | 坏接收时间使盘口不可用，尚未被可信完成事件恢复 |
| no_completed_book | 尚无完成盘口可供使用 |
| not_resolved_by_stream | 文件首尾等未被后续可信消息结算的计划网格，原因未知 |

发生异常且尚未恢复时，保留先前阻断状态；原始消息异常数与网格失效数不同。
异常在下个网格前恢复或出现在休市时，可能不产生交易网格失效。状态说明
采样器当时为什么没有报价，不能证明供应商丢包或市场实际中断。

## 结论与下一步

证据表明当前 500ms 超龄规则是校准日缺少长期标签的主要来源，不能简单归因为
“原始数据不够”。更宽年龄恢复了完整奖励数据的一个前提，但不能证明旧报价
仍可成交、专家有优势、订单评价足够或 IRL 能识别权重。**没有改变默认规则，
没有计算策略盈利，也没有据此宣称完成 IRL。**

下一阶段可以把严格基线与已声明的年龄敏感性接入时间尺度 IRL，先检查成熟
订单/专家可表示性并保留失败诊断。扩大校准期也应预先声明，不按盈利挑日。
全量数据准备需要继续处理边界 session 与降级来源；本次只覆盖五个开发日。
