# 论文定义对照与复现边界

依据仓库内 `1679894.pdf` 全文，页码为 PDF 的物理页码。对应 PR #2 的 2026-09-29 审阅。**本项目是受 FMATO 启发的课程工程实验，尚未复现原论文算法全貌或实验数值。因果性测试通过不能证明论文复现成功。**

## 公式与实现

- 第 4 页 Eq.(2)：`E(T) = mid(t_trade + T) - mid(t_trade)`，单位为价格差。默认 `paper_price_difference` 使用此单位，不做 P99 缩放、不裁剪。卖单乘方向符号是项目扩展，论文没有完整规定卖单实现细节。
- 第 4 页 Eq.(3)：多尺度线性加权，论文**明确规定权重和为 1**，但没有明确规定非负。默认非负单纯形是本项目附加假设；另跑 `SignedBox` 敏感性，允许负权重且每项在 `[-1,1]`、总和为 1。这一盒约束也是项目假设，不是恢复了论文未公开的优化器。
- `--reward-definition normalized_return` 是独立工程模式：方向相对收益除以训练绝对收益 P99，再将加权奖励裁剪到 `[-1,1]`。单位、尺度、约束存入 JSON；与价格差模式不可当作同一实验混读。归一化模式平均裁剪后的在线奖励不再严格等于先平均特征再线性打分。
- 第 5 页 Eq.(5)：固定期间内 `M` 笔订单的平均评价。本项目校准特征已改为 `sum(features) / matured_order_count`；每事件暴露另列 `event_feature_exposure`。零成熟订单时均值未定义，`order_feature_expectation_defined=false`；仅为让现金参加有限策略求解，约定其特征为零向量。开仓、退出都是订单；不等于完整交易收益。
- 第 5 页 §3.3.2 的 OE 没有直接扣执行费用。默认订单奖励不扣成本；`Sensitivity-NetOE-FixedWeights` 在固定权重下单独扣单边费用。所有模式的资金账本始终扣实际点差、滑点、手续费，避免把奖励和净利润混为一谈。
- 第 5 页 §3.3.1 强调高频交易关心极端预测（文中 top one-in-one-thousand）。本项目 ME 只评价超过执行门槛的信号，校准与在线使用相同门槛；尚未实现论文级极端分位协议。阈值命中不意味着一定成交（仍受持仓、延迟等限制）。

## 选择器：保留变体，撤回等价命名

### CausalEventUCB（不是论文 Algorithm 2）

论文以固定期间交易并更新模型评价，示例为 5 分钟。本项目每个事件选择一次模型。ME 在信号的最长前瞻期结束后更新；OE 在执行事件的最长前瞻期结束后更新。对决策 `d`：

- 有成交：`r_d = score(mean(features(order) for order caused by d))`。
- 无成交：`r_d = 0`，同样等待反馈期结束。
- 每个成熟决策恰好一条反馈；选择次数包含待反馈决策，均值分母只数已成熟决策。探索项使用已发出决策数，是明确的延迟反馈启发式，未主张标准 UCB 理论保证。
- OE 反馈归属触发成交的决策模型；平仓的资金收益归属原开仓模型。两个归属各有含义，不混用。

这不是 Eq.(5) 的固定期间订单均值，不能沿用 `FMATO-OE-UCBS` 名称。

### CausalShadowARS（不是论文 Algorithm 3）

论文交易一个期间后，对其他模型在当前时刻之前的固定历史窗口重新回测，例子是过去 30 分钟。本项目没有实现该历史窗口重回测：影子账户从回放起点连续运行，窗口只保留最近 `window_events=300` 个事件内**到达**的成熟奖励；OE 平均订单反馈，ME 平均过门槛信号反馈。空窗口分数约定为 0，全空时轮换。策略名统一为 `Variant-*-CausalShadowARS`，不会再写作论文 ARS。

因此目前没有 PaperARS 历史窗口不变性测试，也没有声称满足 Algorithm 3。若下一阶段实现，应以真实时间截取过去窗口、明确起始账户状态及回放频率，并测试改动窗口外及未来数据不会影响本次评分。

## 数据、模型库与验证边界

论文第 4 页 §3.2 的候选模型来自不同特征集、历史时期和市场分布，并每周更新。当前五种算法使用同一特征集、同一训练段，只是异构算法库。这是核心方法差异，未以新增几种算法声称覆盖原设计。

第 3 页 §3.1 描述定时快照并讨论交易所不同发布间隔；第 5 页实验描述还出现每秒 4 次快照。本项目默认回测仍使用**不等间隔订单簿事件**，10/30/90 为事件数。已有独立的 0.5 秒快照工具与 session 时间标签数据准备入口，见下节；它们尚未接入默认回测。事件级配置、读取接口和结果使用 `events`；`tick_size` 与 `slippage_ticks` 仅保留价格最小跳动的合法含义。

论文第 7 页使用较长训练测试区间，且与本项目 CME/ICE 合约、市场制度、合约乘数、费用、盘口更新机制不同。本项目不复现论文 j2005/i2005 等品种的实验数值。文件内不重叠窗口可能相关，不是跨日独立重复；汇总只做描述，不给独立样本置信区间。

四段流程隔离测试集。静态集成不依赖学习奖励，先在验证段选定共同门槛，再按此门槛重放校准段、拟合权重，随后仍在同一验证段选 c 和固定模型。这不是测试泄漏，但多次使用短验证段会选择过拟合；尚未实现嵌套时间验证。

专家、门槛、c、固定模型选优均保存 `tied_best_candidates`、`tie_break_rule` 与绝对美元容差 `1e-9`。并列按预先声明顺序取首项；报告必须显示“并列最佳”，不宣称唯一最优。论文 Algorithm 1 在此仅以有限策略最大间隔优化近似，收敛与专家可表示性分开报告。

## 定时快照的数据准备（2026-10-01）

`prepare_snapshot_dataset.py` 是独立数据入口，读取已生成的因果快照，按 ESZ5
交易 session 缓冲。按毫秒目标时刻生成 Eq.(2) 的中间价差，另存相对收益标签。
默认 5/15/45 秒对应半秒网格上的 10/30/90 ticks；这一频率选择是明确的项目设定，
没有消除论文两处快照频率表述的差异，也尚未覆盖论文所述一小时以上奖励。

与直接 `shift(-h)` 不同，标签要求精确目标格存在、与起点属于同一连续区间，
并且到期时刻严格早于下一切分。任意缺格或交易暂停都断开连续区间；
动量与波动率从新块重新预热，不能用零值伪装过去不存在的行情。
“任意缺格都隔离”是保守工程假设，不是论文公开的完整缺失值协议。

版本化日历仅覆盖当前 ESZ5 数据所需 trade date 2025-09-15 至 2025-12-15。
按 Chicago 时区处理夏令时，常规时段采用 17:00 至次日 16:00，15:15–15:30 暂停。
感恩节根据配置中链接的 CME 原表，将 11/27 早盘、暂停后重开和 11/28
12:15 CT 早收盘归到 11/28 trade date；并不把 11/27 当成完全没有行情的一天。
暂停两侧仍禁止相互借用标签和滚动特征。临时停机由数据质量与实际缺格表示。

输出保留全部有效 session 快照与失效标记，JSON/中文报告记录计划覆盖、缺口、
各尺度有效样本及互斥失效原因。来源哈希、前缀/降级状态、日历哈希与源码哈希可追溯。
只统计输入所覆盖的时间范围，不宣称未提供的相邻 UTC 文件属于已观测数据。

该步骤不选择训练测试日期，不拟合模型，不在线更新奖励，也不模拟成交。
旧执行引擎仍按事件数计成熟、持仓和延迟；尚未实现按时间到期反馈、跨日训练、
按周模型库或论文 Algorithm 2/3 的选择协议。因此不能把新数据准备结果当作新回测收益。

## 快照时间回放基线（2026-10-01）

`run_snapshot_backtest.py` 接入上述数据集，使用独立 `TimeExecutionEngine`。
本节更新前一阶段“时间到期尚未实现”的状态；旧默认事件入口仍保持原口径。

- 按原文对应：§3.1 的定时快照与历史训练、第 4 页 Eq.(2)–(4) 的多尺度
  中间价差。ME 从预测时刻、OE 从实际成交时刻起计时，最长尺度到期后才观察。
  精确目标缺失或中间存在缺口/session 转换时，不借用后面的第 h 行或假零值。
- 工程假设：默认半秒网格、500ms 最短执行延迟、15s 最短持仓复核、Ridge alpha=1、
  固定等权奖励；主动单按当时一档盘口加滑点成交。卖单方向扩展与美元成本沿用账本。
  训练末端清除最长奖励尺度跨界样本，标准化与模型只在训练段拟合。
  当前训练窗口独立重算精确目标和预测收益；prepared 数据的旧切分不参与样本
  筛选。旧标签声称有效时核对行情与到期时刻，失效缓存不删除当前合法样本。
- 信息边界：只用当前因果特征决定是否预测；预热行情仍盯市。离线标签及
  learning_ready 不参与回放决策，运行前从执行输入移除。测试末尾行情不因奖励
  未成熟而删除。源质量、数据/日历/源码哈希、模型和实际依赖存入独立 JSON。
- 缺口规则：看到缺口后撤销旧意图，在首条可交易行情退出，计入缺口损益；
  不根据未来 continuous_block 回溯退出。已知日历暂停/收盘，在最后一个严格
  早于边界的网格退出；关闭边界快照只观察。退出格缺失时延续持仓到下一条可交易
  行情；期末不能退出时保留真实仓位和未实现盈亏。这些不是论文公开的完整风控规则。
- 静态基线只记录成熟反馈，不按反馈换模型；OE 统计成熟订单均值仍使用 Eq.(5)
  的订单分母，但没有实现其固定选择期间。新引擎明确拒绝旧动态选择器，防止混用
  事件窗口、per-decision 与 per-order 反馈。没有声称完成 Algorithm 2/3。
- 该短窗口入口尚未实现：IRL 时间管线、跨日四段实验协议、长于一小时的正式奖励校准、不同
  特征/历史期的按周轻模型库。时间配置允许较长前瞻，不代表已验证长期奖励方法。

该入口输出 `result_kind=snapshot_time_baseline`，不是旧事件结果 schema 3。
同目录中文报告由新入口直接生成；旧报告与看板不会读取这一结构。小窗口属于开发
验证，不挑选正收益窗口，结果与未能形成有效特征的尝试见
[时间回放验证记录](time_backtest_validation_2026-10-01.md)。

## 完整 session 四段开发协议与长期样本审计（2026-10-01）

新增 `run_session_experiment.py`，补充跨日训练与日期协议，更新上一阶段的状态。
依据论文物理第 3 页 §3.1 每日优化、第 3–4 页 §3.2 历史训练、第 4 页
Eq.(2)–(4)/Algorithm 1 多尺度奖励与 IRL、第 7 页时间隔离实验。

- 工程协议：train/calibration/validation/test 按完整 trade date 连续隔离。
  先冻结配置、prepared 数据/质量、日历、运行源码；运行不接受参数覆盖，修改
  绑定内容必须另存计划。日历 session 使用 `(open,close]`，关闭边界不成交。
- 跨日固定基线：StandardScaler.partial_fit 与两遍 Ridge 充分统计量只使用训练
  日，alpha=1；与批量带截距 Ridge 数学目标相同。每天末端按最长尺度 purge，
  训练标签按当前行情精确重算；旧 prepared 边界不能筛选当前样本。
- 长尺度审计：半秒网格的 10/30/90/270/810/2430/7290 个网格对应
  5/15/45/135/405/1215/3645 秒。末项是为覆盖超过一小时而作的工程延伸，
  不是论文公开的完整超参数；论文 0.5 秒与每秒四次快照的差异仍存在。
  各尺度与全部尺度联合有效量单列，缺格/暂停/收盘原因保留；未来有效条件仅作
  离线审计，不能过滤执行决策，等权中间价差不扣费用，费用由交易账本单列。
- 完整日风险：禁用“文件末行退出”，防止缺尾数据让策略提前看到终点；仅根据
  已知日历及当时行情处理退出。不能平仓的日保留未实现盯市，总净盈亏未定义。
  每日独立 100,000 USD 账户，不复利、不年化；现金与固定模型逐日保留。
- 未完成：校准/验证仅保留诊断阶段，尚无时间尺度 IRL、参数选择、按周多特征/
  历史期模型库或 Algorithm 2/3。四段调度不能等同于完整 FMATO 学习管线。

五个真实 session 的开发检查中，10-01 校准段没有完整 3645 秒样本，不能直接
开展该协议的七尺度 IRL；三个固定 Ridge 诊断日均亏损。既不更换有利日期，也不
根据结果改门槛。详见 [跨日协议验证记录](session_protocol_validation_2026-10-01.md)。

## 快照缺格原因与报价年龄对照（2026-10-01）

`run_snapshot_audit.py` 依据原文第 3 页 §3.1 的定时 tick 和第 4 页
Eq.(2)–(4)/Algorithm 1 的长期奖励数据前提，补充缺格来源诊断。论文没有公开
最大报价年龄、采样未完成事件和缺失值协议；本节所有状态及候选都是工程设定。

- 采样器增加只读网格观察回调和互斥跳过原因，盘口选择逻辑不变。超龄与事件
  未完成分开，坏盘口标记/非法盘口/不可信接收状态分开。异常状态持续到可信
  完整盘口恢复；原因只说明当前不能采样的观测状态，不证明供应商故障。
- 已由可信消息结算的网格与日历 `(open,close]` 相交，休市排除，文件首尾未
  结算网格单列。扩大年龄生成的休市前来源报价仍由日历拒绝。消息接收静默与
  完成盘口年龄不同：静默大于 2 秒不是“中断”的事实认定。
- 先冻结相同五 session、六 UTC 源分区、500ms 网格和七尺度，比较
  最大年龄 500/1000/2000ms；源文件、索引、日历、源码绑定哈希。所有候选都
  必须进入汇总，不能运行中新增参数或按收益筛选。保留旧 500ms 数据与结果。
- 标签仍要求精确目标和整个区间连续；短时重复使用可信完成盘口受声明的年龄
  上限约束，不跨长空档、暂停或 session 填充。诊断不训练模型、拟合 IRL 或
  计算交易收益，样本更多不等于盘口更可信。默认最大年龄仍为一个网格周期。

对照结果见 [快照年龄与长期标签验证](snapshot_age_validation_2026-10-01.md)。
源代码加入诊断后，旧冻结计划会按预期拒绝新的源码哈希；重跑需另存新计划，
不能把旧实验身份复用到新源码上。

## 指标与产物

- `raw_sign_accuracy` 评估连续收益预测的符号；`thresholded_signal_accuracy` 评估过门槛后含零信号的三类准确率；`active_signal_accuracy` 仅评估过门槛样本；`signal_coverage` 给出覆盖率。逻辑回归另存真实分类器 argmax 准确率与混淆矩阵，不能把期望收益符号当作分类器输出。
- `unmatured_fill_rewards_at_end` 包含末尾全部尚未成熟成交，既有较早开仓也有期末平仓。
- `environment-snapshot.txt` 只是运行环境版本快照，不是完整跨平台依赖锁文件；CI 安装兼容依赖范围，结果另记实际版本。
- JSON schema 升为 3，旧结果必须重新生成。报告、看板与结果使用同一新口径。
