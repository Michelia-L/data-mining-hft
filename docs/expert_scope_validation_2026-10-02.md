# OE 专家来源对照验证（2026-10-02）

本轮把“专家不在在线动作集”拆成一个可检验的工程假设：只改变专家筛选
范围，同时保留完整奖励比较集合。全候选控制的 3 个年龄 × 3 个约束拟合
及原 sum_only 门控与 PR #17 归档逐字段相等。库内口径在 1000/2000ms
获得可通过现有校准门控的权重，500ms 仍阻断。没有激活权重或运行动态交易。

## 论文依据与方法边界

已通读原文，并重点重读物理第3页 §3/Eq.(1)、第4页 §3.2–3.3/
Eq.(2)–(4)/Algorithm 1、第5页 Eq.(5)/Algorithms 2–3，以及第7页
§4.2 的切分与基线。Eq.(1) 把动作对应到轻模型；Algorithm 1 第1步从
训练回测取得专家，但未公开候选范围、具体专家筛选规则或生产参数优化器。
因此“按校准净利选专家”及以下两组都标为项目假设，不能称为论文唯一规则。

- `all_candidates`：在全部已结算候选中选净利最高者，保留原控制。
- `online_library`：在全部已结算库内候选中选净利最高者。即使亏损或无成熟
  OE 也先选该专家，随后检查可计算性；不从有观察子集中挑选次优者。
- 两组都面对同一完整可计算 P×H 矩阵：现金、固定 Ridge、12个库策略按原
  成熟资格进入优化。库外参照不会因为不能在线选择而被删掉。所有并列按
  原候选顺序记录与消歧，范围列表顺序不会重排矩阵。
- simplex、signed_box、sum_only 三组全部保留。前两者是额外约束敏感性，
  sum_only 保留 Eq.(3) 的和为1并沿用最大间隔后最小 L1 消歧。完整有限
  候选响应近似 Algorithm 1 的策略搜索；权重不具有唯一识别性。
- 旧门控保持：奖励拟合可用、专家在库内、完整在线库均有已结算且足量的
  成熟 OE。通过只表示校准条件具备，不表示统计证据充分或存在盈利专家。
