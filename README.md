# data-mining-hft

个人研究记录项目：使用高频行情数据尝试复现论文核心方法。

## 参考论文
- **论文**：《Auto-tuning of price prediction models for high-frequency trading via reinforcement learning》
- **文件**：`1679894.pdf`

## 数据说明
本项目基于以下两个高频 MBP-10 订单簿数据文件开展实验：
- `databento_glbx.mdp3_mbp_10.csv`
- `databento_ifeu.impact_mbp_10.csv`

> **说明**：因数据文件体积较大（均超过 1GB），未上传至 GitHub 仓库。本项目仅作为个人实验记录，若有数据需求欢迎提交 Issue。
